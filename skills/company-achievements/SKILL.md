# Company Achievements Skill

## Purpose
Help users learn about the company's notable achievements — awards, certifications, milestones, growth metrics, successful product launches, and industry recognitions — by locating verified sources and presenting an accurate summary.

## When to use this skill
- The user asks "what has the company achieved?" or "what awards has the company won?"
- The user wants a timeline or list of company milestones (e.g., funding rounds, user growth, product launches).
- The user asks about certifications or industry recognitions the company holds.
- The user wants achievements for a specific year, team, or product.

## Instructions
1. Identify the scope of the request (e.g., all-time achievements, a specific year, a specific team/product, a specific category like awards or certifications).
2. Search the company's official sources for achievements (e.g., press releases, "About Us" or "Newsroom" pages, internal announcements, achievements log, or repository documentation).
3. Summarize each achievement with key facts: what was achieved, when, and any relevant context (e.g., awarding body, metric value, milestone significance).
4. Present achievements in chronological order (most recent first, unless the user requests otherwise) for readability.
5. Always cite the source of each achievement so the user can verify it.
6. If no achievements matching the request can be found, say so clearly instead of fabricating information.
7. Avoid exaggerating or embellishing accomplishments beyond what the source material states.

## Notes
- Only report achievements that are documented in an official or verifiable source; do not speculate.
- If an achievement listing is outdated, note that newer information may exist and suggest checking the latest company announcements.
